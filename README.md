# Security Input Validation CLI



Консольное приложение на Python для проверки корректности и безопасности пользовательского ввода

(email, телефон, ИНН, банковские реквизиты и др.).



Проект создан в учебных целях и демонстрирует подходы к secure coding и input validation,

которые применяются при тестировании веб-приложений и API.



---



## Зачем это нужно в пентесте



Ошибки валидации пользовательского ввода часто приводят к:

- XSS

- SQL Injection

- Logic flaws

- некорректной обработке данных на сервере



Данная утилита позволяет:

- моделировать корректный и некорректный ввод,

- анализировать, какие данные проходят проверки,

- демонстрировать слабые и сильные стороны валидации.



---
